# Workflow: launch or promo (a product, feature or brand)

1. **Brief:** product, audience, the one promise, proof (a real number or a
   real screen), call to action, length (15–30 s), format.
2. **Structure:** hook (the pain or the result, outcome language) → the
   promise → how it works in ≤ 3 beats → one proof → name + CTA. Value lands
   by the second beat.
3. **Exploration vs production** (`references/prompt-patterns.md`): to find a
   look, permission prompts work ("like it's your showreel, go all out"). To
   ship, a spec with seconds and bans ("no bounce, no particles, no lens flares").
4. **Template:** `kinetic-showreel` for type-driven promos; add
   `ui-cursor-demo` or `terminal-code` segments for proof shots.
5. **Brand:** palette by role in `palette`; fonts only from the bundle or
   files the user owns with a license you can name.
6. Build → check → sheet → render → verify. Deliver 16:9 and offer 9:16 and 1:1 cuts.

Never invent metrics, logos of customers or testimonials.
