# Prompt patterns that worked (Opus 5.5 community, Sep 2026)

Full sources and discussion: the FinalStudio research report (`research/opus-motion-design/informe.html` in the project).

## Showreel permission (@achxvi, Pocketsflow)
> make a dynamic 15-second motion graphics video about [PRODUCT] that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out. … make a video where a character talks about [PRODUCT] and how people can use it …

Use it to explore a style. Then pin the result down in a storyboard.

## Five-scene explainer (@alex_prompter)
> Build a 30-second animated explainer … 5 scenes: the customer's problem, what I do, how it works in 3 steps, one proof point, and my name at the end.

For tutorials, map it to: problem → key idea → steps → result → check.

## Shot-by-shot brief
A second-by-second timeline plus bans ("smooth easing, no bouncing, no particles"). This is what `storyboard.json` encodes.

## One shape, never cut (@twoclipping)
One element morphs between UI states on a 120 BPM grid. Use it for software-procedure tutorials.

## File to lesson (Claude Design)
> Analyze the content of this file, extract the main learnings, and create an educational animation.

This is the entry point of the FinalStudio product. This skill replaces "create an animation" with the verified, storyboarded loop.
